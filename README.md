## 🌟 Основні можливості (Key Features)

- 🔍 **Моніторинг процесів у реальному часі**: Автоматично виявляє всі запущені програми на Linux, які відтворюють аудіо (через PipeWire / PulseAudio).
- 📊 **Живі VU-метри (60 FPS)**: Поруч із кожною програмою та мікрофоном відображається плавний анімований індикатор гучності (піковий рівень / RMS із зонами Green-Yellow-Red та Peak-Hold).
- 🎯 **Точковий вибірковий запис (Pinpoint Audio Capture)**:
  - Обирайте будь-яку кількість конкретних програм (браузер, плеєр, месенджер).
  - Окремо обирайте один чи кілька підключених мікрофонів.
  - Жодних зайвих системних звуків чи сповіщень у записі — лише вибрані джерела.
- ⚙️ **Гнучкі налаштування формату**:
  - **Формати**: `MP3` (стиснутий) та `WAV` (без втрат, PCM).
  - **Бітрейт**: `128k`, `192k`, `256k`, `320 kbps`.
  - **Режими збереження**:
    - **Single File (Master Mix)**: Усі обрані джерела зводяться в один стереофайл.
    - **Separate Files (Multitrack Stems)**: Кожна програма та мікрофон записуються в окремий синхронізований файл у папці сесії.
- 🎨 **Сучасний естетичний UI**: Преміальна темна тема (Dark Glassmorphism), швидкі перемикачі, таймер тривалості та кнопка швидкого відкриття папки записів у файловому менеджері Linux.
- ⚡ **Низьке навантаження**: Завдяки нативній інтеграції з `pulsectl` та `parec` використання процесора становить менше 2-3%.

## 🛠️ Встановлення та запуск (Quickstart)

### 1. Запуск з системного меню Linux (Desktop App)
Додаток уже встановлено та зареєстровано у вашій системі:
- Відкрийте меню програм (Super / Меню програм / Applications).
- Знайдіть **`S_Audio_Pin`** та натисніть на нього, щоб запустити одним кліком!

### 2. Запуск через термінал
Ви можете запустити додаток з будь-якого каталогу:
```bash
s-audio-pin
```
Або через `uv`:
```bash
uv run python -m src.main
```

## 🏗️ Архітектура проекту

```text
S_Audio_Pin_Linux/
├── src/
│   ├── models/audio.py         # Моделі даних (AudioSource, RecordingConfig, RecordingSession)
│   ├── config/settings.py      # Збереження конфігурації (~/.config/s_audio_pin/config.json)
│   ├── audio/
│   │   ├── monitor.py          # Моніторинг потоків PipeWire/PulseAudio та розрахунок піків
│   │   ├── recorder.py         # Двигун захоплення аудіо (робота з parec та ffmpeg)
│   │   ├── encoder.py          # Конфігурація кодеків WAV/MP3 та зведення міксу
│   │   └── process_info.py     # Розпізнавання назв процесів та іконок
│   ├── server/
│   │   ├── app.py              # FastAPI REST API & маршрутизація
│   │   └── ws.py               # WebSocket сервер для трансляції VU-метрів
│   ├── ui/
│   │   ├── index.html          # Сучасний інтерфейс
│   │   ├── css/style.css       # Стилі (Dark Glassmorphism, анімації, адаптивність)
│   │   └── js/
│   │       ├── visualizer.js   # 60fps Canvas рендерер VU-метрів
│   │       └── app.js          # Логіка керування та стан інтерфейсу
│   └── main.py                 # Головна точка входу та автозапуск
└── tests/                      # Повний набір юніт- та інтеграційних тестів
```
